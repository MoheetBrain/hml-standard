# Geometry

*HML Standard 1.0 — semantic atlas*

The question each row answers is **not** whether HML proves the concept. It is whether HML can carry its reasoning state losslessly.

| Concept | Role | HML representation | Carry | Manipulate | Verify | Verdict |
|---|---|---|---|---|---|---|
| point / line / plane | primitive objects | ConceptType or declared Objects | yes | yes | LIBRARY | **LIBRARY_GAP** |
| distance | metric between points | FunctionType -> NonNegativeReal | yes | yes | LIBRARY | **LIBRARY_GAP** |
| congruence / similarity | geometric equivalence | Predicate | yes | yes | LIBRARY | **LIBRARY_GAP** |
