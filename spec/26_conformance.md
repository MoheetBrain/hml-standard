# Conformance

*HML Standard 1.0 — 2026-08-27*

What an implementation must do to claim conformance.

[NORMATIVE] See `CONFORMANCE.md` for the full definition. In summary, a conforming
implementation MUST satisfy every rule marked NORMATIVE in `standard/rules.json`, and MUST
be able to reproduce the outcomes recorded in `conformance/RESULTS.json`.

## Normative rules

No rules are registered against this section; the requirements above are enforced through the rules listed in the sections they name.
